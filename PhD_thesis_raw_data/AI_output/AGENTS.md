# Mathematical LaTeX editing in this folder

For revisions of Xiaoxiang Zhou's mathematical LaTeX manuscripts, read
[the personal style skill](skills/zhou-math-latex/SKILL.md) and its linked
[style requirements](skills/zhou-math-latex/references/style-requirements.md)
before editing. These instructions apply to his mathematical manuscripts;
they do not impose this style on unrelated artifacts in this folder.

The current user request and current source take precedence over older
drafts. Preserve preambles, use automatic numbering and external BibTeX,
and follow the requested revision and editor workflow described in the guide.
